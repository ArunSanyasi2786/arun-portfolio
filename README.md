# Arun Sanyasi — Portfolio

Personal portfolio website built with the **"Life in Chapters"** design theme.

## Live Website

[arunsanyasi2786.github.io/arun-portfolio](https://arunsanyasi2786.github.io/arun-portfolio/)

## Tech Stack

- **Next.js 16** (App Router, static export)
- **TypeScript** + **SCSS Modules**
- **GSAP** + ScrollTrigger for scroll-driven animations
- **Lenis** for smooth scrolling
- Deployed via **GitHub Actions** to **GitHub Pages**

## Sections

1. **Hero** — Vermilion introduction with portrait
2. **Story** — Background, experience timeline, leadership
3. **Work** — Featured projects, technical skills
4. **Business & Services** — Freelance services, collaborations, ventures
5. **Contact** — Email, phone, social links, enquiry form

## Development

```bash
cd site
npm install
npm run dev
```

## Build

```bash
cd site
npx next build
```

Static output goes to `site/out/`.
